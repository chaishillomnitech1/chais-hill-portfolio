## 🏁 Getting Started

### Prerequisites
- Git installed on your machine
- GitHub account
- Code editor (VS Code recommended)
- Node.js and npm (for JavaScript/TypeScript projects)

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/chaishillomnitech1/chais-hill-portfolio.git
   cd chais-hill-portfolio
   ```

2. **Install dependencies** (if applicable)
   ```bash
   npm install
   ```

3. **Run the project** (if applicable)
   ```bash
   npm start
   ```

4. **Build the project** (if applicable)
   ```bash
   npm run build
   ```

For detailed onboarding instructions, see [ONBOARDING.md](ONBOARDING.md).

## 🤝 Contributing

Contributions are welcome and appreciated! Please follow these steps:

1. Read the [Contributing Guidelines](CONTRIBUTING.md)
2. Read the [Onboarding Guide](ONBOARDING.md)
3. Fork the repository
4. Create a feature branch (`git checkout -b feature/amazing-feature`)
5. Commit your changes (`git commit -m 'feat: add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Code of Conduct
Be respectful in all interactions. Harassment or abuse of any kind is not tolerated. See [CONTRIBUTING.md](CONTRIBUTING.md#code-of-conduct) for details.

### Development Workflow
- All changes require a pull request
- Pull requests need approval from @chaishillomnitech1
- CI/CD checks must pass before merging
- Follow commit message conventions
- Keep changes focused and atomic

## 🔒 Security

Security is a top priority. If you discover a security vulnerability:

1. **DO NOT** open a public issue
2. Report it privately to @chaishillomnitech1
3. Provide detailed information about the vulnerability
4. Wait for acknowledgment and guidance

For more information, see our [Security Policy](.github/SECURITY.md).
